# Reddit

Title: I built a 22-state Claude mascot collection and included the skill to create more

I've extended a Claude mascot animation reference into 22 activity states for apps: reading, writing, thinking, testing, walking, and more.

The collection includes transparent animated SVGs, a browser preview, a React component, and editable source. I also packaged Mascot Studio, a coding-agent skill for adding characters, animation states, hats, and accessories from a brief.

Example request: "Add a wizard hat to idle, thinking, and walking as new variants; keep the originals." This is an example prompt, not an included variant.

Preview: https://harriszed.github.io/mascot-studio/mascot/
Source, downloads, and skill: https://github.com/Harriszed/mascot-studio

Reference animation by Ayotomiwa Wale-Durojaye. Claude character by Anthropic. Unofficial community project; see the repo's attribution and reuse notice.

I'd love to see what characters or states people make with the workflow.
